# 用户手册（中文）

## 1. 访问系统
- 打开浏览器访问：`http://localhost:3514/`

## 2. 主要功能

### 2.1 查看景点
- 地图上会显示所有景点标注（Marker）
- 点击标注可查看简介，并可直接设为起点或终点

### 2.2 选择起点/终点
- 左侧控制面板选择“起点”和“终点”
- 支持输入关键词搜索景点名称
- 坐标缺失的景点在下拉列表中显示为“（缺坐标）”且不可选择

### 2.3 开始规划
- 点击“开始规划”
- 系统会计算最短路径并在地图上画出路线
- 下方“路径结果”显示途经景点顺序与总距离，以及各景点的开放时间、建议停留时长

### 2.4 景点节点维护（后台）
- 入口：首页控制面板右上角“齿轮”按钮，或直接访问 `http://localhost:3514/admin`
- 新增景点：点击“新增景点”，填写名称（必填）、经纬度、所属区域、开放时间、推荐停留时长等
- 编辑/删除：在列表每行的“操作”列中进行
- 经纬度可留空（后续再补）；**坐标缺失的景点不参与路径计算**，补全坐标后自动恢复可规划
- 保存后无需重启，地图与起终点选择会立即使用最新数据

### 2.5 常用操作
- “交换”：交换起点与终点
- “清空”：清除起点/终点与规划结果

## 3. 常见问题

### 3.1 页面提示“加载节点失败”
- 检查后端是否启动：访问 `http://localhost:8514/api/health`
- 若未启动，建议执行：`docker compose up -d --build`

### 3.2 地图底图无法显示
- 底图来自 OpenStreetMap，离线或网络受限时可能无法加载
- 不影响路径规划与列表展示

## 4. 操作演练（合并）

### 4.1 一键启动
在项目根目录执行：
```bash
docker compose up -d --build
```

启动后访问：
- 前端：`http://localhost:3514/`
- 后端健康：`http://localhost:8514/api/health`

### 4.2 数据加载说明
- 启动后端时：
  - 若数据库无节点：从 `nodes.csv` 导入节点到 PostgreSQL
  - 读取 `edges.csv`：若存在则用其构图；否则按地理距离自动生成边

### 4.3 路径规划演练
1) 在左侧选择起点、终点（或在地图 Marker 弹窗中设置）
2) 点击“开始规划”
3) 在地图查看路线，在控制面板查看路径节点列表与每段距离

### 4.4 接口示例
```bash
curl -sS http://localhost:8514/api/nodes
curl -sS "http://localhost:8514/api/path?from=JIEFANGBEI&to=HONGYADONG"

# 新增景点（坐标可留空）
curl -sS -X POST http://localhost:8514/api/admin/nodes \
  -H 'Content-Type: application/json' \
  -d '{"name":"新景点","lat":29.56,"lng":106.57,"region":"渝中区","openHours":"09:00-18:00","stayMinutes":60}'

# 更新 / 删除景点
curl -sS -X PUT http://localhost:8514/api/admin/nodes/<id> \
  -H 'Content-Type: application/json' \
  -d '{"name":"新景点","lat":29.56,"lng":106.57,"region":"渝中区"}'
curl -sS -X DELETE http://localhost:8514/api/admin/nodes/<id>
```
